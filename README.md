## 相态分工（重要）

- **滗析槽只吃液体**：静置 24h，上层清液 = 更纯的同一种药剂，下层 = 沉淀。
- **过滤台只吃液体 + 滤纸**：按孔径拦截污染物，每类保留 0.7% 下限。
- **气体洗涤塔只吃气体**：洗涤除杂提纯，不改变化学身份。
- **气体灌装台只吃气体 + 空容器**：**P1b1 起只产工业钢瓶 + 真实纯度 tag**（医用/化学纯 SKU 保留为 legacy、不再产出）；大型储气桶只做工业档。
- 气体不能滗析、液体不能洗涤，数据层 / 输入过滤 / 独立校验三层强制。

## 滗析与过滤都不可能完全提纯

- 滗析只移除可沉降的物理污染物 / 不溶碎屑（各 85%），游离的化学污染物（2 μm）、
  重金属（12 μm）、微生物等**完全保留**。
- 三档滤纸孔径：化学滤纸 22 μm / 精密滤纸 5 μm / 无灰定量滤纸 2 μm；
  每类污染物仍保留 **0.7% 残留下限**，所以纯度**永远 < 100%**，过滤链达不到满值。
- 想提纯只能反复滗析 / 过滤 / 洗涤，逐档逼近，不能清零。

## 温度控制（可玩性关键）

- **温度计 `thermometer`**：点击循环切换实验温度档 **0 冷 / 1 常温 / 2 加热 / 3 高温高压**。
- 温度档是 T2–T4 配方**能否匹配**的条件：档位不对，投料再对也不出产物。
  合成反应釜 / 电解槽 / 高压合成塔 / 分馏柱 / 结晶器 / 滴定台等夜间设备的配方都带 `temp` 条件。
- 实时加热台是另一条温度通道（按每秒真实温度驱动 6 条热反应），与温度档互不替代。

## 热修复记录（v0.5.2 → v0.9.6 P0 整改）

**现象**：v0.5.0 在游戏「已安装模组」列表报错（`NullReferenceException`）、模组无法启用、设置面板显示 `cfg_dangerous` 等原始键。

**根因（`Player.log` 已证实）**：`FreeChem.ModEntry.OnEnable → RegisterWildNetwork → ModHelper.AddNetworkUpgrade → PlayerStore.Instance → PlayerStore..ctor` 抛 NRE。
`OnEnable` 在主菜单运行，而 `AddNetworkUpgrade` 内部会**惰性构造** `PlayerStore`；主菜单下该构造抛异常 → `[ModLoader] Init failed` → 模组被禁；
Init 失败又导致**本地化未加载**，于是设置面板显示原始键 —— 两个现象是同一个根因。

**修复**：① Wild Network 注册从 `OnEnable` 移到 `OnGameLoaded`（先 `PlayerStore.HasInstance` guard，未就绪则跳过并 `log.Warning`，再注册，整体 try/catch）；
② `OnDisable` 的 `RemoveNetworkUpgrades` 加 try/catch（半初始化/主菜单状态不得再抛）；③ 设置分区名改中文「玩法」/「调试」。

**状态**：仅编译 + 静态证据（build 0 错 0 警、本地化 300 条齐备）；**未实机验证**「列表不再报错 / 模组可启用 / 设置面板全中文 /
王尔德 4 张卡（气体商人、气体订单、排风服务、进阶排风服务）是否正常出现」。
