## C. 本机程序集静态核对（命令可复现）

```python
# 在 Managed 目录里搜 API 成员名
folder = r"D:\SteamLibrary\steamapps\common\Probably Stolen\Probably Stolen_Data\Managed"
blob = b"".join(open(p,'rb').read() for p in glob.glob(folder + r"\*.dll"))
# 命中：SetSpriteAndShapeFromMod / SetSprite / UpdateSprite / RefreshSprite /
#       SetSpriteFromCapacity / StartCoroutine / WaitForSeconds / IEnumerator /
#       AddNetworkUpgrade / OnNetworkUpgradeUnlocked / CHEMICAL_SUPPLIES / MEDICAL /
#       NARCOTIC / POISON / Contaminant / HeatingPlate / Fuel / Alcohol / Suspicion / AddHeat ...
# 未命中（说明官方未暴露）：FilterPaper / Beaker / Retort / Wick / AlcoholLamp /
#       securityHeat / crimePoints / AddSuspicion / investigationProgress
```

**结论**：`AddHeat`/`BalanceHeat`/`ClearHeat`/`SEC_SUSPICION_PENALTY` 等标识符存在，但归属类与语义各不相同（详见 `docs/api-findings.md` §2.2：`AddHeat` 是植物遗传热、`BalanceHeat` 是空方法、`SEC_SUSPICION_PENALTY` 是 Lou 探员剧情常量），**没有通用的「加嫌疑度」API**；官方指南与 APIChanges 均无记载。

**第 13 轮 Lead 决策**：采用 `docs/api-findings.md` §2.4 的 guard 方案，**已接入**原版治安部 —— 有毒气体排放折算写入
`SecData.CommitCrime(SecData.ENDANGERMENT, units × 10 × 排风倍率)`；先 `PlayerStore.HasInstance` 判空，
**默认开启、可在模组设置 `vanilla_security` 关闭**（未文档化成员，随版本可能变）。
模组自有计数（`ModData` 键 `exhaust_raw`）仍保留用于提示框展示与排风倍率校验。**写入量平衡与调查节奏未实机验证。**

**第二轮核对（第 11 轮，结论待 `docs/api-findings.md` 落笔）**：
- 运行时换图：`SetSprite` 家族签名官方未给；实现方改用**官方文档化的 `SetSpriteAndShapeFromMod` 裸 spriteKey 重复设置**（`ChemMachines.SetMachineVisual`，内部 `set spriteAtlasPath=modId / spritePath=<id>` 或 `<id>_on`，只在状态变化时切），13 台设备 + 加热台已接线，**游戏内效果未验证**。
- 游戏版本号：`AssemblyInformationalVersion` 用于核对 `manifest.xml` 的 `<GameVersions>`；**manifest 现填 `0.46`，与 api-findings §4 结论一致**（本机 Steam buildid 26525552）。
