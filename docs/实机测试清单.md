# 实机测试清单（review-fixes 分支）

给在**有游戏文件的机器**上测试的人（或本地 Claude）用。目标：确认 `review-fixes` 分支能用真实游戏 DLL 编译，并在游戏里验证 `docs/code-review-2026-11-10.md` 第八节列出的修复。

## 0. 拉代码

```bash
git clone https://github.com/fksans/-FreeChem-ziyi.git FreeChem-ziyi
cd FreeChem-ziyi
git checkout review-fixes
```

`review-fixes` 已经包含「解压源码」和「审查报告」两个提交，切到这个分支就够了。

## 1. 编译

需要 .NET SDK 8，以及正版游戏目录（项目引用游戏自带的 `Assembly-CSharp.dll` 等程序集）。`GameDir` 末尾必须有反斜杠：

```bash
dotnet build src/FreeChem.csproj -c Release -p:GameDir="D:\SteamLibrary\steamapps\common\Probably Stolen\\"
```

- 期望 **0 错误**。如果有错误，把完整输出贴回来：这次改动只用占位类型编译过，游戏 API 的签名可能有出入，最容易出错的是 `WaterHelper.RemoveAndReturn`、`GraphUtils.TryAcceptAll` 的返回值类型，以及 `Liquid` 的字段类型。
- 产物在 `src/bin/Release/netstandard2.1/FreeChem.dll`。

## 2. 离线校验（不需要游戏也能跑，建议先跑）

```bash
python tools/logic_check.py
python tools/validate.py
python tools/output_fit_check.py
dotnet run --project tools/logic-harness/LogicHarness.csproj -c Release
```

期望：`logic_check` 全部通过；`validate` 0 FAIL（有游戏程序集时 WARN 应少于 106）；`output_fit_check` 0 组放不下；harness 输出「结论：全部通过」。

## 3. 安装

1. 把 `src/bin/Release/netstandard2.1/FreeChem.dll` 复制到仓库的 `FreeChem/FreeChem.dll`。
2. **先备份**游戏里现有的 `Probably Stolen\Mods\FreeChem\`（例如改名为 `FreeChem.bak`）。
3. 把仓库的整个 `FreeChem/` 文件夹复制成 `Probably Stolen\Mods\FreeChem\`。
4. 启动游戏，在 Mods 菜单确认 FreeChem 已启用、没有显示「Init failed」，在模组设置里打开「调试模式」（`debug_mode`）。
5. 进店后按 **F10** 打开调试生成窗口，输入数字 ID 生成物品到后柜台（输入 `list` 查看编号，或查 `src/ChemItemIds.cs`）。

**建议用新存档测试**；旧存档另测一次读档（第 4 节最后一组）。

## 4. 游戏内测试项

每一项记录：通过 / 失败 / 现象。出问题时附上 `Player.log` 里以 `[FreeChem]` 开头的相关行（Unity 默认路径：`%USERPROFILE%\AppData\LocalLow\<开发商>\Probably Stolen\Player.log`）。

### 容器与液量
- [ ] **烧杯能倒液**（审查 2.1）：生成烧杯和一瓶盐酸，选中盐酸瓶再点烧杯，液体倒进烧杯。顺便看烧杯的**贴图有没有被换成原版水瓶贴图**。
- [ ] **试管架能打开**：生成试管架，打开后是 2×3 的格子，只能放试管。
- [ ] **半瓶不反应**（1.1）：把一瓶盐酸倒出一部分，放进电解槽，机器**不开工**；tooltip 显示「不足一整瓶」。
- [ ] **药剂瓶不能灌水**（1.2）：半瓶盐酸，用原版水罐往里倒，**倒不进去**。两瓶半瓶盐酸互相倒，可以合并。
- [ ] **扫描仪**（1.3/1.4/2.2）：用成分仪扫描盐酸，显示 HCl/酸 36%、水 64%，总液量是**真实剩余量**；连续扫几次、换别的物品再扫回来，文字不会变成原版内容。
- [ ] **烧杯凑份**（3.4）：把一整瓶盐酸倒进烧杯（500 ml），烧杯放进电解槽，能电解；反应后烧杯还在，里面的液体被扣掉。

### 机器
- [ ] **氯碱法能跑**（3.1）：盐水 + 电解槽（温度计调到「加热」档）+ 电池，过夜后输出格里出现氯气、氢气、烧碱三件。
- [ ] **没配方不开工**（3.8）：往机器里放一件随便的药剂，过夜后**投料还在**，没有变成废渣。
- [ ] **输出满不开工**（3.2）：先把输出格塞满，再放正确投料，过夜后投料还在，后柜台没有多出东西。
- [ ] **气瓶会被消耗**：在反应釜的气瓶槽放氢气钢瓶，配合能用到氢气的配方，反应后钢瓶变成空钢瓶回到输出格。
- [ ] **冷凝吸收看温度**（4.4）：氯化氢 + 原版水罐（至少 500 ml 水）放进冷凝塔，常温档能反应、高温高压档不反应；反应后**水罐和滤芯都还在**，只少了 500 ml 水（5.1）。
- [ ] **滗析产出沉淀**：滗析后沉淀出现在机器输出格里，而不是后柜台。

### 加热台
- [ ] **状态显示**（2.4）：鼠标悬停加热台，显示温度、档位、状态、进度秒数。
- [ ] **原版酒精按真实量消耗**（1.6）：原版小瓶酒精放进燃料槽，灌进灯里的燃料约 175 ml（不是 350），瓶里的酒精真的变少了，空瓶留在燃料槽里。
- [ ] **水瓶不能当燃料**（1.7）。
- [ ] **超温降解**（3.6）：盐酸放进加热台、调到高档 160°C，温度超过 130°C 后产出废渣、盐酸被消耗。调到低档 99°C 时能正常蒸馏提纯。
- [ ] **输出满暂停**：输出格塞满时，反应到时间后停在「已完成，输出格已满」，投料不被消耗；腾出位置后继续产出。

### 原版联动与数值
- [ ] **毒性显示**（3.7）：盐水、二氧化碳、氢气**不再**显示「致命」；氯气、氢氧化钠固体仍显示致命。
- [ ] **接触反应**（5.3）：本模组盐酸点本模组碳酸钙会反应；本模组盐酸点原版碱性溶液瓶**不会**把原版瓶吃掉。
- [ ] **旧存档读档**：用改动前的版本存一个档（里面有液体药剂瓶），换成新版读档，液体瓶的体积和成分都正常，没有被清空（`ComponentVersion` 从 3 升到 4，会触发迁移）。
